# Zahlenraten

Ein Spiel, bei dem der Benutzer eine Zahl erraten muss. Anfragen werden über JavaScript an ein PHP-OOP-Backend gesendet, das das Spiel verarbeitet.

## Voraussetzungen

- PHP 7.4 oder höher
- Webbrowser

## Erste Schritte

### PHP-Server

#### PHP installieren

Falls PHP noch nicht installiert ist, verwenden Sie diese Anleitung: https://www.php.net/manual/en/install.php

1. Öffnen Sie Ihr Terminal und wechseln Sie in den Projektordner.

```bash
cd /Pfad/zu/ChallengeOne
```

(Nicht notwendig, wenn Sie das Terminal in VS Code verwenden, da es direkt im Projektordner geöffnet wird). 2. Starten Sie den PHP-Server:

```bash
php -S localhost:8000
```

(Falls Port 8000 bereits belegt ist, versuchen Sie es mit 8081, 8080 usw.)

3. Öffnen Sie Ihren Browser und rufen Sie folgende Adresse auf:

```
http://localhost:8000

```

(oder einen der anderen von Ihnen gewählten Ports)
